# 02 · 工作（山 · 晨雾山脊）/ Work · Mountain

> **概念：拾级而上。** 顶部晨雾山脊 hero 立气场，往下滚进入近白阅读画布；左侧固定竖向目录随滚动高亮。气质：沉静、克制、严谨可靠——动效比主页收敛，靠留白和发丝线撑场。
>
> 主色 `--accent:#4A6B73`（雾岩青）。继承 `00` 全部 token 与 `.glass/.reveal/.lift/i18n`。
>
> **页面名暂用「工作 / Work」**；之后定了（拾级 / 行知 / 问径）替换 hero 标题即可。

## 4. JS（追加进 `js/main.js`）

```js
// —— 工作页：目录滚动高亮（scroll-spy）——
(function(){
  const links = [...document.querySelectorAll('.sidenav .nav-item')];
  if(!links.length) return;
  const map = new Map(links.map(a => [a.getAttribute('href').slice(1), a]));
  const spy = new IntersectionObserver(es=>{
    es.forEach(e=>{
      if(e.isIntersecting){
        links.forEach(a=>a.classList.remove('active'));
        map.get(e.target.id)?.classList.add('active');
      }
    });
  }, { rootMargin:'-45% 0px -50% 0px' });   // 视口中线触发
  document.querySelectorAll('.block').forEach(s=>spy.observe(s));
})();
// 平滑滚动
document.documentElement.style.scrollBehavior = 'smooth';
```

> `.reveal` 的滚动揭示沿用 `00` 里的 IntersectionObserver，无需重复写。
