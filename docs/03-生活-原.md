# 03 · 生活（原 · 草原 / 田野）/ Life · Plains

> **概念：松弛而温暖。** 整站最活泼的一页——配色更暖、字体更圆、加几个克制好玩的小互动和彩蛋。但底子仍是 `00` 那套设计语言：留白、低饱和、一页一主调，活泼≠杂乱。
>
> 四块全做重点：**性格(ENFJ) · 爱好 · 宠物 · 美食排行榜**。主色 `--accent:#7E9B5B`（草绿）+ `--accent-warm:#E0A94A`（麦金）。

## 4. JS（追加进 `js/main.js`）—— 互动与彩蛋

```js
(function(){
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;

  // 蒲公英种子飘落
  const sky = document.querySelector('.seeds');
  if(sky && !reduce){
    for(let i=0;i<14;i++){
      const s=document.createElement('span'); s.className='seed'; s.textContent='✺';
      s.style.left=Math.random()*100+'%';
      s.style.fontSize=(8+Math.random()*10)+'px';
      s.style.setProperty('--dx',(Math.random()*120-60)+'px');
      s.style.animationDuration=(8+Math.random()*8)+'s';
      s.style.animationDelay=(-Math.random()*8)+'s';
      sky.appendChild(s);
    }
  }

  // 点击迸发（爱心 / 撒花）
  function burst(x,y,set){
    if(reduce) return;
    for(let i=0;i<14;i++){
      const s=document.createElement('span'); s.className='spark';
      s.textContent=set[Math.floor(Math.random()*set.length)];
      s.style.left=x+'px'; s.style.top=y+'px';
      s.style.setProperty('--dx',(Math.random()*180-90)+'px');
      s.style.setProperty('--dy',(-(60+Math.random()*140))+'px');
      s.style.fontSize=(14+Math.random()*14)+'px';
      document.body.appendChild(s); setTimeout(()=>s.remove(),1100);
    }
  }
  document.querySelectorAll('[data-poke]').forEach(el=>
    el.addEventListener('click',e=>burst(e.clientX,e.clientY,['❤️','💛','🐾','✨'])));
  document.querySelector('.rank-1')?.addEventListener('click',e=>
    burst(e.clientX,e.clientY,['🎉','😋','⭐','🍜']));

  // ENFJ 名牌翻面
  document.querySelector('[data-flip]')?.addEventListener('click',function(){ this.classList.toggle('flipped'); });
})();
```

> 特质条的"充能"靠 `.reveal.in` 触发，沿用 `00` 的滚动揭示，无需另写。所有迸发/飘落都在 `prefers-reduced-motion` 下自动关闭。
