# 00 · 设计系统总纲 / Design System

> 这是整个个人网站的「地基」。颜色、字体、间距、玻璃材质、动效、双语切换全部在这里统一定义，三页（主页·海 / 工作·山 / 生活·原）共用同一套 token，只在**主强调色**和**背景意象**上做区分。
>
> **给 Claude Code 的总指令：** 严格按本文件实现 `css/common.css` 里的 `:root` token 与公共类；任何颜色、字号、圆角、动效时长都必须引用变量，禁止写魔法数字。三页只允许覆盖各自的 `--accent` 系列与背景图，其余继承。

---

## 0. 设计总原则 / Principles

1. **高级感来自克制，不是堆料。** 敢留白，少即是多。
2. **清新 = 高明度 + 低饱和**，不是糖果色；每页只用**一种**主强调色，其余靠中性灰和留白撑场。
3. **背景要有空气感与层次**：自然照片在底，上面叠柔焦 / 渐变蒙版 / 噪点，再叠薄玻璃，形成"远—中—近"三层景深，而非平涂。
4. **动效讲究"慢入快出 + 跟手"**，只在关键时刻发力（入场、悬停、滚动揭示），不到处乱动。
5. **可访问性是底线**：对比度达标、支持键盘、尊重 `prefers-reduced-motion`。

## 2. 颜色 / Color Tokens

写进 `css/common.css` 的 `:root`。中性色全站共用；强调色用 `body` 上的页面类切换。

```css
:root{
  /* —— 中性 / Neutrals（全站共用）—— */
  --bg:        #F8FAFB;   /* 冷调近白，主背景 */
  --surface:   #FFFFFF;   /* 纯白，仅卡片少量使用 */
  --ink:       #1B2A33;   /* 主文字，带蓝的深石墨，不用纯黑 */
  --ink-2:     #5A6B73;   /* 次要文字 */
  --ink-3:     #9AA7AD;   /* 说明 / 占位 / 时间戳 */
  --line:      rgba(27,42,51,.08);  /* 发丝分隔线 */
  --shadow:    rgba(27,42,51,.10);  /* 柔和投影 */

  /* —— 间距尺度 / Spacing（8 基准）—— */
  --s-1:4px; --s-2:8px; --s-3:12px; --s-4:16px;
  --s-6:24px; --s-8:32px; --s-12:48px; --s-16:64px;
  --s-24:96px; --s-32:128px;

  /* —— 圆角 / Radius —— */
  --r-sm:8px; --r:16px; --r-lg:24px; --r-pill:999px;

  /* —— 容器宽度 —— */
  --w-page:1120px;   /* 主容器 */
  --w-read:680px;    /* 正文阅读宽度 */

  /* —— 动效 / Motion —— */
  --ease:cubic-bezier(.22,1,.36,1);        /* 慢入快出，默认 */
  --ease-soft:cubic-bezier(.65,0,.35,1);   /* 双向柔和 */
  --t-fast:180ms; --t:320ms; --t-slow:560ms;
}

/* —— 各页主色（覆盖在 body 上）—— */
body.page-home{   /* 海 */
  --accent:#2E8BA0; --accent-soft:#7FC3D1; --wash:#EAF4F6;
}
body.page-work{   /* 山·晨雾岩青 */
  --accent:#4A6B73; --accent-soft:#8AA0A3; --wash:#EEF1F2;
}
body.page-life{   /* 原·草绿 + 麦金 */
  --accent:#7E9B5B; --accent-soft:#AFC489; --accent-warm:#E0A94A; --wash:#F2F3EA;
}
```

> 配色用法：大面积是 `--bg` + 留白 + 背景图，强调色**只点缀**在按钮、链接、关键标题下划线、图标上。切忌大面积铺强调色。

## 3. 字体 / Typography

走 **衬线做标题、无衬线做正文** 的杂志混排，刻意避开 Inter/Roboto 这类"AI 脸"。中英文各配一套，双语切换时整体气质保持一致。

```html
<!-- 放进每页 <head>，Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400;9..144,600&family=Hanken+Grotesk:wght@400;500;600&family=Noto+Serif+SC:wght@500;700&family=Noto+Sans+SC:wght@400;500&display=swap" rel="stylesheet">
```

```css
:root{
  /* 标题 / Display：英文衬线 Fraunces，中文思源宋体 */
  --font-display:"Fraunces","Noto Serif SC",serif;
  /* 正文 / Body：英文 Hanken Grotesk，中文思源黑体 */
  --font-body:"Hanken Grotesk","Noto Sans SC",system-ui,sans-serif;
}

/* —— 字号尺度（rem，基准 16px，约 1.25 模数）—— */
.t-display{ font:600 clamp(2.4rem,5vw,3.5rem)/1.1 var(--font-display); letter-spacing:-.01em; }
.t-h1{ font:600 clamp(1.8rem,3vw,2.4rem)/1.2 var(--font-display); }
.t-h2{ font:600 1.5rem/1.3 var(--font-display); }
.t-h3{ font:600 1.25rem/1.4 var(--font-body); }
body { font:400 1rem/1.65 var(--font-body); color:var(--ink); }
.t-small{ font-size:.875rem; } .t-caption{ font-size:.75rem; color:var(--ink-3); }
```

> - **主页 / 工作页** 用上面这套（衬线标题，文艺又严谨）。
> - **生活页** 可把 `--font-display` 临时换成更圆润活泼的字体（例如英文 `Quicksand`、中文继续思源黑体加粗），保持字号系统不变，只换"气质"。这条等做生活页时再定。

## 4. 玻璃材质 / Glass（已按"更薄更通透"调过）

你原来那版玻璃方向是对的，这里把它收得更高级：**降低填充不透明度、单根发丝边框 + 顶部内高光**。

```css
.glass{
  background: rgba(255,255,255,.10);
  backdrop-filter: blur(16px) saturate(120%);
  -webkit-backdrop-filter: blur(16px) saturate(120%);
  border: 1px solid rgba(255,255,255,.18);
  box-shadow:
    0 8px 32px var(--shadow),
    inset 0 1px 0 rgba(255,255,255,.28);   /* 顶部一道极细内高光，玻璃感关键 */
  border-radius: var(--r-lg);
}
/* 深色背景上用的玻璃（如山脊背景较暗处）可改 background: rgba(255,255,255,.08) */
```

> 名片就用这个 `.glass`。要点：玻璃越薄越高级，里面信息越少越贵气。

## 5. 动效 / Motion

```css
/* 滚动揭示：默认隐藏，进入视口加 .in 触发 */
.reveal{ opacity:0; transform:translateY(16px); transition:opacity var(--t-slow) var(--ease), transform var(--t-slow) var(--ease); }
.reveal.in{ opacity:1; transform:none; }

/* 悬停：卡片轻抬 + 强调色描边 */
.lift{ transition:transform var(--t) var(--ease), box-shadow var(--t) var(--ease); }
.lift:hover{ transform:translateY(-4px); box-shadow:0 16px 40px var(--shadow); }

/* 尊重无障碍：关闭所有大动效 */
@media (prefers-reduced-motion: reduce){
  *{ animation:none !important; transition-duration:.01ms !important; }
  .reveal{ opacity:1; transform:none; }
}
```

```js
// js/main.js —— 滚动揭示 + 错峰
const io = new IntersectionObserver((es)=>{
  es.forEach((e,i)=>{ if(e.isIntersecting){ e.target.style.transitionDelay=(i%6*60)+'ms'; e.target.classList.add('in'); io.unobserve(e.target);} });
},{threshold:.12});
document.querySelectorAll('.reveal').forEach(el=>io.observe(el));
```

> 主页保留你已有的：**跟随鼠标的柔光、名片流动高光、头像呼吸光晕、三层视差**。这些是主页的记忆点，工作 / 生活页则以"滚动揭示 + 悬停轻抬"为主，更克制。

## 6. 中英双语切换 / i18n（零构建方案）

最适合个人站、最方便你以后加内容的做法：**内容直接写在 HTML 里**，每段中英各写一份，用 `lang` 属性标注，靠一个按钮切换 + `localStorage` 记住选择。**不需要单独维护翻译字典。**

```html
<!-- 写法：同一处内容，中英各一份 -->
<h1 class="t-display">
  <span lang="zh">你好，我是唐瑞遥</span>
  <span lang="en">Hi, I'm Ruiyao Tang</span>
</h1>

<!-- 右上角切换按钮（建议做成玻璃小药丸 .glass .lang-toggle） -->
<button class="lang-toggle" onclick="toggleLang()">EN / 中</button>
```

```css
/* 按当前语言显隐 */
html[data-lang="zh"] [lang="en"]{ display:none; }
html[data-lang="en"] [lang="zh"]{ display:none; }
```

```js
// 放进 js/main.js，越早执行越好（避免闪烁）
(function(){
  const saved = localStorage.getItem('lang') || 'zh';
  document.documentElement.dataset.lang = saved;
})();
function toggleLang(){
  const next = document.documentElement.dataset.lang === 'zh' ? 'en' : 'zh';
  document.documentElement.dataset.lang = next;
  localStorage.setItem('lang', next);
}
```

> 以后加内容只要"中英各写一句"即可，不碰任何 JS。
