# 01 · 主页（海）/ Home · Sea

> **概念：对望。** 人像在左、名片在右、海在底。鼠标移动时三层视差 +名片朝光标 3D 转身，像在与访客对视；海面波光浮动，头像呼吸光晕；底部两个入口「工作 / 生活」悬停时透出各自页面的颜色。
>
> 一屏 hero，不需要滚动。所有 token、`.glass`、双语切换都继承 `00 设计系统总纲`。

## 5. 交互 JS（写进 `js/main.js`）

```js
// —— 主页：三层视差 + 名片 3D 转身 + 名片高光跟手 ——
(function(){
  const card   = document.getElementById('card');
  const shine  = card && card.querySelector('.card-shine');
  const layers = [...document.querySelectorAll('[data-depth]')];
  if(!layers.length) return;
  if(matchMedia('(prefers-reduced-motion: reduce)').matches) return; // 无障碍

  let raf = null, mx = 0, my = 0;
  window.addEventListener('mousemove', e=>{
    mx = e.clientX/innerWidth  - .5;   // -0.5 ~ 0.5
    my = e.clientY/innerHeight - .5;
    if(shine){
      const r = card.getBoundingClientRect();
      shine.style.setProperty('--mx', ((e.clientX-r.left)/r.width *100)+'%');
      shine.style.setProperty('--my', ((e.clientY-r.top )/r.height*100)+'%');
    }
    if(!raf) raf = requestAnimationFrame(apply);
  });

  function apply(){
    raf = null;
    layers.forEach(l=>{
      const d = parseFloat(l.dataset.depth) * 100;
      let t = `translate3d(${ -mx*d }px, ${ -my*d }px, 0)`;
      if(l === card) t += ` rotateY(${ mx*6 }deg) rotateX(${ -my*6 }deg)`; // 朝光标转身
      l.style.transform = t;
    });
  }
})();
```

> 别忘了 `00` 里那段**双语切换 IIFE** 也要在 `main.js` 里、且尽早执行，避免切换时闪烁。
